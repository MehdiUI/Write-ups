# 🛠️ Module 11 : Security Solutions

Ce module présente les outils technologiques qui permettent de protéger, détecter et corriger les failles.

## 🧠 Ce que je retiens de ce module
- **Les pare-feux** : Première ligne de défense. La différence entre un filtrage basique et un NGFW est cruciale.
- **Le SIEM** : Le cerveau qui centralise et corrèle les logs. Sans lui, un analyste est aveugle.
- **L'IDS (Snort)** : Le chien de garde du réseau. Savoir lire ses alertes permet de repérer les intrusions.
- **Les scanners de vulnérabilités** : L'outil pour corriger les failles (Patching) avant qu'elles ne soient exploitées, en se basant sur les scores CVSS.
