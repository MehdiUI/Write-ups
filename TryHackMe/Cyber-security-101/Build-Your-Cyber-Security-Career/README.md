## 🧠 Ce que je retiens de ce module
- **La sécurité est un équilibre** : Confidentialité, Intégrité, Disponibilité.
- **L'orientation** : Le parcours confirme mon choix pour la **Blue Team** et le rôle d'Analyste SOC L1.
- **L'investissement en formation** : La formation continue est essentielle, et savoir démontrer son ROI est une compétence stratégique.
