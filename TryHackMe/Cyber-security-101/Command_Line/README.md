# 💻 Module 4 : Command Line

Ce module se concentre sur l'utilisation de la ligne de commande, un outil indispensable pour tout analyste SOC ou administrateur système, que ce soit sous Windows ou Linux.

## 📝 Rooms du module

| Room | Description | Statut | Write-up |
|---|---|---|---|
| **Windows Command Line** | Commandes CMD de base pour l'administration Windows. | ✅ Terminé | [Lire](./windows-command-line.md) |
| **Windows PowerShell** | Utilisation avancée de PowerShell (cmdlets, piping). | ✅ Terminé | [Lire](./windows-powershell.md) |
| **Linux Shells** | Découverte des différents shells (Bash, Zsh, Fish) et scripting. | ✅ Terminé | [Lire](./linux-shells.md) |

## 🧠 Ce que je retiens de ce module
- La ligne de commande permet d'automatiser des tâches et d'aller plus vite que l'interface graphique.
- PowerShell est extrêmement puissant grâce à son approche orientée objet (piping).
- Connaître les bases du Bash est obligatoire pour analyser les logs sous Linux.
