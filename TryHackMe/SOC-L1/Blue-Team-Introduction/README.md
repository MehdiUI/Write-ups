# 🔵 Module : Blue Team Introduction (SOC Level 1)

Ce module est la porte d'entrée du parcours **SOC Level 1**. Il permet de comprendre le rôle d'un analyste SOC junior, ses missions quotidiennes et les outils qu'il utilise.

## 📝 Rooms du module

| Room | Description | Statut | Write-up |
|---|---|---|---|
| **Junior Security Analyst Intro** | Simulation d'une journée type d'un analyste L1 (triage, escalade, blocage d'IP). | ✅ Terminé | [Lire](./junior-security-analyst-intro.md) |
| **Humans as Attack Vectors** | Comprendre le facteur humain (phishing, social engineering, insider threats) et le rôle du SOC. | ✅ Terminé | [Lire](./humans-as-attack-vectors.md) |
| **SOC Fundamentals** | (Déjà validé dans le parcours Cyber Security 101) | ✅ Terminé | [Lire](../../Cyber-security-101/Defensive_Security/soc-fundamentals.md) |
| **Splunk: The Basics** | Découverte de l'outil SIEM Splunk. | ⏳ À venir | — |

## 🧠 Ce que je retiens de ce module
- **Le rôle du L1** : Le premier rempart de la défense. Il trie les alertes, élimine le bruit et escalade les vraies menaces.
- **L'humain au centre** : Les attaques ciblent souvent les personnes. La sensibilisation et la détection des signaux faibles sont essentielles.
